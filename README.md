# كتالوج المنتجات المصرفية

صفحة ويب تعرض المنتجات والمبادرات المصرفية الإسلامية على إدارة المصرف، لتختار منها ما يُعدّ له دراسة جدوى كاملة.

- **١٧ مبادرة استراتيجية** و**١٥٠ منتجاً** في ثلاثة أقسام: الودائع والاستثمار، والائتمان والتمويل، والحسابات والبطاقات والخدمات.
- بحث وفلترة حسب القسم والفئة والصيغة الشرعية.
- **ملف القرار**: يُؤشَّر على المنتج بزر «اختيار»، وتُحدَّد له أولوية (عالية، متوسطة، منخفضة) مع ملاحظة.
- التصدير: ملف Excel (CSV)، أو مذكرة قرار مطبوعة فيها خانات التوقيع، أو نسخ القائمة نصاً.
- تُحفظ الاختيارات في متصفح المستخدم فقط.

## التشغيل
افتح `index.html` في المتصفح مباشرة، أو فعّل GitHub Pages على هذا الفرع (Settings → Pages).

## البيانات
- `data/bank-products.xlsx`: الملف المصدر.
- `assets/data.js`: البيانات مستخرجة منه وتقرأها الصفحة.
